## Flujo de trabajo

- `master`: versión estable. Nadie trabaja directamente aquí.
- `develop`: rama donde se integran los avances del equipo.
- `feature/nombre-tarea`: una rama por tarea, creada desde `develop`.

Reglas:
1. Crear tu rama `feature/...` desde `develop`.
2. Hacer commits pequeños con mensajes claros.
3. Subir tu rama y abrir un Pull Request hacia `develop`.
4. Otro compañero revisa antes de unir los cambios.
